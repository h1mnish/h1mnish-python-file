Q6. Two Sum – Find Two Numbers Whose Sum Equals Target**

O(n) time

```
def two_sum(arr, target):    seen = {}    for i, num in enumerate(arr):        complement = target - num        if complement in seen:            return [seen[complement], i]        seen[num] = i    return []
```

Q7. Longest Substring Without Repeating Characters**



O(n) time

O(k) space



Sliding Window approach.

```
def longest_substring(s):    seen = {}    left = 0    max_length = 0    for right, char in enumerate(s):        if char in seen and seen[char] >= left:            left = seen[char] + 1        seen[char] = right        max_length = max(max_length, right - left + 1)    return max_length
```

**Test:**

```

```

## **Q19. Top 3 Highest-Paid Employees in Each Department**

Window Function

```
SELECT Name, Department, Salary
FROM (
    SELECT *,
           DENSE_RANK() OVER (
               PARTITION BY Department
               ORDER BY Salary DESC
           ) AS rnk
    FROM Employees
) AS ranked
WHERE rnk <= 3;
```

**Important:**

- `PARTITION BY` department-wise ranking karta hai.
- `ORDER BY Salary DESC` highest salary ko first rakhta hai.
- `DENSE_RANK()` equal salaries ko same rank deta hai.

```
ON e.DeptID = d.DeptID;
```

Result: Rahul–IT, Aman–HR, NULL–Finance.



Q21. Binary Search**

O(log n) time

```
def binary_search(arr, target):    left, right = 0, len(arr) - 1    while left <= right:        mid = left + (right - left) // 2        if arr[mid] == target:            return mid        elif arr[mid] < target:            left = mid + 1        else:            right = mid - 1    return -1
```

Q22. Bubble Sort**

O(n²) time

```
def bubble_sort(arr):    arr = arr.copy()    n = len(arr)    for i in range(n):        swapped = False        for j in range(n - i - 1):            if arr[j] > arr[j + 1]:                arr[j], arr[j + 1] = arr[j + 1], arr[j]                swapped = True        if not swapped:            break    return arr
```

**Test:**

Q48. Find First Repeating Element in an Array**



High Priority

&#x20;O(n) Average Time | O(n) Space



**Concept:** Set for tracking visited elements.

```
def first_repeating(arr):    seen = set()    for num in arr:        if num in seen:            return num        seen.add(num)    return None
```

**Test:**

```
first_repeating([10, 5, 3, 4, 3, 5, 6])# 3first_repeating([1, 2, 3, 4])# None
```

Q49. Find Second Most Frequent Element**



Medium–High

&#x20;O(n) Average Time | O(n) Space



**Concept:** Counter se frequency count karna.

```
from collections import Counterdef second_most_frequent(arr):    freq = Counter(arr)    if len(freq) < 2:        return None    sorted_freq = sorted(        freq.items(),        key=lambda x: x[1],        reverse=True    )    return sorted_freq[1][0]
```

**Test:**

```
second_most_frequent([1, 1, 1, 2, 2, 3])# 2second_most_frequent([4, 4, 5, 5, 6])# 5
```

**Remember:** Counter frequency count karta hai, sorted frequency descending order mein arrange karti hai.

Note: Equal frequencies hone par original insertion order ke basis par result aayega.

Q50. Count Pairs with a Given Sum**



Medium–High

&#x20;O(n) Average Time | O(n) Space



**Concept:** Dictionary se previous elements ki frequency store karna.

```
def count_pairs(arr, target):    freq = {}    count = 0    for num in arr:        complement = target - num        count += freq.get(complement, 0)        freq[num] = freq.get(num, 0) + 1    return count
```

**Test:**

```
count_pairs([1, 5, 7, -1, 5], 6)# 3count_pairs([1, 1, 1, 1], 2)# 6
```
